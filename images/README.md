# images/ — スクリーンショット置き場

案内ページに載せるスクリーンショットをここに置く。

## 掲載前の必須手順（写り込み検分）

**公開リポジトリのため、置いた瞬間に全世界へ公開される。**
掲載前に必ず以下を確認すること（本体リポ status.md の申し送り「スクショ素材は公開前に写り込み検分」）：

- 実在リスナーの名前・コメント内容・金額が写っていないか
- 配信 ID・トークン・パスワード・ローカルパス等が写っていないか
- タスクバー・通知など画面外周の写り込み

## 差し込み待ちの枠（ページ側にプレースホルダあり）

| ファイル名（案） | 内容 | 差し込み先 |
|---|---|---|
| `v1-main.png` | 初代（v1）のメイン画面 | `index.html` の「v2 開発の背景」節（HTML コメントで雛形記載済み） |

v2 のスクショ（機能紹介用）を追加する場合の候補は、本体リポ
`docs/screenshots-c2/`・`docs/screenshots-dep3/`（テストデータのみ写っているもの）。
検分のうえコピーして、各ページの `<figure>` で参照する。
