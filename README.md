# 読み分けちゃん2 — 公式配布ページ

配信のコメントを、複数の声で読み分けて読み上げるツールです。
ツイキャス・YouTube・ニコニコ生放送・Twitch・ふわっち・ミクチャ・Kick・ミラティブのコメント取得に対応しています。

**最新版は v2.22a です（2026-10-13 公開）。**
