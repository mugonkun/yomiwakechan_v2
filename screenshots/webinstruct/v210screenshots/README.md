# v210screenshots — v2.10 の画面写真の置き場

v2.10（2026-08-27 公開）で画面構成が変わったため、v2.00 時点の写真
（一つ上の `webinstruct/` にあるもの）を差し替えるための新しい写真をここに置きます。

ファイル名は自由（日本語可）。置いたら副官へファイル名を伝えれば、
HTML への差し込み・alt テキスト・figcaption・各ページ冒頭の
「写真は v2.00 時点」の断り外しまでを行います。

## 欲しい写真と行き先（優先順）

| # | 撮るもの | 行き先 | 差し替える現行の写真 |
|---|---|---|---|
| ① | **タイムライン稼働中**（コメントが流れ、ポインタ帯に読み上げ中の 1 件が乗っている） | ホーム最上部の 2 枚組・左／「v2.10 の更新内容」のタイムライン項の直下 | `通常稼働時1.jpg` |
| ② | **タイムライン待機中**（上部コントロール領域と [一括起動して受信開始] が読める） | 配信者向けガイド 2 章ステップ 4 | `初回起動2.png` |
| ③ | タイムライン設定タブのフィーダー欄（配信 ID の入力欄） | 配信者向けガイド 2 章ステップ 3 | `初回起動1.png` |
| ④ | ステータスタブ稼働中（統計・エンジンスキャン結果） | 配信者向けガイド 2 章ステップ 5 | `通常稼働時1.jpg` |

①だけでも差し込めます。③④は無くても文章で通ります。
初期設定ウィザードの写真は不要（司令官裁定 2026-08-27）。

## 撮るときの注意

- **アクセストークンの設定画面を写さない。** 貼り付け欄に実値が表示される作りです。
- **配信者 ID の欄を写さない。**
- リスナー名が並ぶ画面は、テスト枠のものであれば可。
- ホーム最上部の枠は **横長 8:5 に切られ、左上を基準に詰められます**。
  ウィンドウ全体のキャプチャなら破綻しません。
