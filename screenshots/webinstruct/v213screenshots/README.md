- **アクセストークンの設定画面を写さない。** 貼り付け欄に実値が表示される作りです。

  （接続先がローカルなら鍵欄は空でよい）。

- リスナー名・コメント本文が並ぶ画面は、テスト枠（FeederScenario の架空リスナー）のものであれば可。
  実リスナーが写るものは差し込む前に判定します。
- ホーム最上部の枠は **横長 8:5 に切られ、左上を基準に詰められます**。
  ウィンドウ全体のキャプチャなら破綻しません。
